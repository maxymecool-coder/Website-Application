# Fixed Action Patterns
**Details**
True to the name, these are actions that the animals innately had so that they can function in their environment. A baby does not learn how to suckle milk, it already knows that.  A squirrel who has been on a liquid diet its whole life still understands how to crack a nut. Though there is a crucial difference between this and simple determinism, the FAP can improve. This is only the blueprint, the very starting point of it can do, the baby can nurse so it can get more nutrients, the squirrel can do the same as well. And all of this is learnt from experience, from the environment that these animals exist in, showing us a perfect example of gene-environment interaction.
