# The Machine Table View of Mind
**Details**
Functionism allows us to describe the brain abstractly, like a computer program. We can easily make a table to present how a person's state (being mad) and then receiving a negative input (a stupid question) can lead them to an output (yelling) and to a different state (guilty). This allows cognitive psychologists and neuroscientists to effectively study and tackle their studies on the brain and mind more.

They will break it down to how the visual and sensory and such stimuli makes us react, the states that we are in and so on and so forth. Same for how that cognitive psychology tackles environments and genes and how that interacts with us and so on with the brain
