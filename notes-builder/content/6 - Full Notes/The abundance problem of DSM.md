# The abundance problem of DSM
**Details**
Throughout the years, the DSM has seen updates, with these updates come with dozens additional disorders. Psychologists and others have argued about how necessary these additions are considering that a lot of these disorders can be solved with the same methodologies and such like that. Moreover, the similarities between these illnesses usually causes comorbidity, meaning that a second illness can be found additionally from the primary disorder. More than that, they have also been questioned about how valid the categories of the diagnostic tool is, if it truly reveals information that is useful about the patient and so on.
