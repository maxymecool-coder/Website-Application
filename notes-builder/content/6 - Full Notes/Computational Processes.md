# Computational Processes
**Details**
The mechanical application of logic involves two distinct, inverse processes: Evaluation and Satisfaction. Evaluation is a forward-chaining where, given a truth assignment, one calculates the resulting truth value of a complex sentence. Satisfaction on the other hand is reverse-search. Given a logical sentence, the goal is to discover which possible truth assignments render the sentence true. which is the truth table. While conceptually simple, this method reveals a critical complexity constraint: the size of a truth table grows exponentially ($2^n$) with the number of constants. Consequently, proving satisfiability for large systems becomes a computationally expensive task, distinguishing it sharply from the linear simplicity of evaluation.
