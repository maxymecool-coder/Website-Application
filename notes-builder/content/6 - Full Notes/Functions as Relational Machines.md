# Functions as Relational Machines
**Details**
A **function** is formally defined not as a dynamic process, but as a static logical structure: specifically, a subset of a Cartesian product. A function $f$ from $A$ to $B$ is a set of ordered pairs $<a, b>$ such that for every input $a$, there is exactly one unique output $b$. While formally a set, it is intuitively understood as a machine that deterministically maps inputs (Domain) to outputs (Range).

Functions can be combined through **Composition** ($g \circ f$), where the output of $f$ becomes the input of $g$. This is analogous to connecting two hoses; the flow (data) moves through the first to reach the second. This operation is associative, allowing complex chains of transformations to be built from simple mappings.
