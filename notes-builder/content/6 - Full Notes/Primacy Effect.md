# Primacy Effect
**Details**
The **primacy effect** is a cognitive bias where items presented at the beginning of a list or sequence are recalled more accurately than items in the middle. This phenomenon is a component of the serial position effect.

The leading explanation for the primacy effect is that the initial items receive more cognitive rehearsal. When the first few items are presented, there is ample time and working memory capacity to repeat them, which facilitates their transfer from short-term memory into more stable **long-term memory**. As more items are added to the list, attention becomes divided, and the opportunity for rehearsal diminishes, making subsequent items harder to encode into long-term storage.
