# Reconsolidation
**Details**
Different from extinction, reconsolidation works based on the premise of eliminating the trace of the memory or overwriting it while extinction merely suppresses it with a conditioned stimulus. This nature of extinction however allows the CS to be able to creep up again under novel circumstances (unable to generalize) and perhaps lose effect over time if not maintained. Research indicates that when a long-term memory is reactivated (recalled), it briefly becomes "labile" or unstable for a short window of time. During this window, the memory requires protein synthesis to restabilize.

And due to this being able to be changed, if a chemical or a cognitive reaction is fast enough… well the memory can be rewritten and perhaps rid of, the main reason that it is argued to be better than extinction.
