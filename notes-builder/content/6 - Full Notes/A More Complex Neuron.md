# A More Complex Neuron
**Details**
The neurons that Dale laws instated were all about how each had one neurotransmitter to put out, in all of its axon terminals. This allowed for easy classifications like “serotonergic,” “dopaminergic,” and so on, suggesting a straightforward signaling system. But of course this was disproved by the works of Jerry Letvin about co-transmission. It is now understood that each neuron can release different transmitters, packaged together in the same vesicle. These may have different characteristics, functions, and so on. 

The second principle, Dale’s first law, is concerned with action potential. A basically “all-or-nothing” principle that every axon terminal will fire out neurotransmitter. Again, Jerry Lettvin disproved this, by demonstrating branch point failure. This is a phenomenon where the action potential does not travel down every branch. Combining with the above, this meant they can choose which neurotransmitters to be released.
