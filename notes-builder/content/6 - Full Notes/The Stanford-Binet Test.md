# The Stanford-Binet Test
**Details**
The **Stanford-Binet IQ test** is a foundational intelligence test that operationalized the psychometric approach through an age-scaled design. Items on the test are designated by the age at which a typical child can answer them correctly. This allows an examiner to determine a person's **mental age**, which can then be compared to their chronological age.

The test uses an **adaptive testing** method, where the difficulty of questions is adjusted based on the test-taker's performance, making the process efficient. The final score is an IQ score calibrated so that the mean at any age is 100. While it provides an overall IQ, it also yields subscores for more specific skills like visual reasoning and short-term memory.

This test was highly flawed for its time, and more effective tests have derived since its inception, although it is still the reason that this all started.
