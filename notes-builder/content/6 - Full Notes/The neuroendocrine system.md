# The neuroendocrine system
**Details**
This system is highly related in psychopathology, as it contains the HPA axis and other systems. The HPA axis is central to the body's response to stress, how it controls and release hormones to deal with the problems and so on.

When we are faced with a threat or a hardship, the hypothalamus releases corticotrophin releasing factor (CRF), which then communicates with the *pituitary gland*. This then releases adrenocorticotrophic hormone, which then travels via the blood to the adrenal glands. The outer layers of these glands are called adrenal cortex; it promotes the release of cortisol. Cortisol is highly relevant as it it the stress hormone. It takes a long time for it to peak, about 20 to 40 minutes. And after the threat has remitted, it can take up to an hour for it to return to baseline levels.

**Supporting Content**
This system has a negative feedback loop, meaning the more ACTH sent down, more Cortisol there is, and that Cortisol travels up to the hypothalamus to tells it to slow down the ACTH and eventually stop.
