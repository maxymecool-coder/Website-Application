# Semantics in Logic
**Details**
In [[Propositional Logic]], "meaning" is detached from the real-world significance of the words used. Instead, it derives entirely from Truth Assignments, binding them to a binary value of 1 or 0 (true or false). Logic is unconcerned to what the constant represents; only to how the truth values propagate through it.

The semantic rules defining this propagation are rigid, while operators like conjunction (AND) and disjunction (OR) align relatively well with intuition, Material Implication ($\Rightarrow$) presents a unique conceptual challenge. This is defined by the condition of falsifiability: an implication is considered false only when the antecedent is true and the consequent is false.
