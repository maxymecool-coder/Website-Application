# The process of learning
**Details**
This process is quite similar to how long-term memory is created in the mind. It begins with encoding, which includes the fact that our brain turn our perceptions into chemical and electrical changes that can form a mental representation of the patterns we have seen. These can be called memory traces, or short-term memory. Our lives are generally guided by the ephemera that clutter our short-term memory which are soon forgotten. We have to find ways that makes our brain understands which memories are worth more so that it focuses on strengthening it.

Here comes the next step, consolidation. New learning is labile, which means it can be altered and remembered wrongly. The process that we consolidate is believed to include the brain replaying and rehearsing the learning to fill in gaps and connect it to previous experiences. This is why we need to make it difficult, as it forces our neurons to focus to truly work the memory in as well as find for us gaps in knowledge for the brain to do, aka reconsolidation.

Lastly is retrieval, which is the process of getting the memory back for us to use. This is where all the work from consolidating it comes, if we have strengthened it well, we will be able to retrieve it easily.
