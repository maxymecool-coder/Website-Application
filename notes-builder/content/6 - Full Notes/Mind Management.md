# Mind Management
**Details**
The idea of sorting tasks by the state of mind or the type of attention. Deriving from [[Different kinds of attention]] and [[Schemas to learn quicker]], we can inherently come to the conclusion that we have different kinds of attentions that are suited for different things, and so we should try to maximize the effectiveness of such things. For example, if we want to settle to reading, we can make it be at the same place/position (lying down) and with some music and amenities alongside. Same for if we go for any other tasks.
