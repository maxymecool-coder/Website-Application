# Pairs and Cartesian Products
**Details**
Mathematics also requires structure where order matters, this is achievable for the Ordered pair $<a, b>$. Unlike sets, where $\{a, b\} = \{b, a\}$, an ordered pair strictly distinguishes the first element from the second. The **Law of Ordered Pairs** states that $<a, b> = <c, d>$ if and only if $a=c$ and $b=d$.

This is the bridge between abstract algebra and geometry. By associating the geometric points with ordered pair of numbers, distinct mathematical fields can merge. This concept scales up to ordered n-tuples. The set of all possible ordered pairs between two sets $A$ and $B$ is the **Cartesian Product** ($A \times B$). If set $A$ has 2 elements and set $B$ has 3, their Cartesian product contains 6 ordered pairs, creating a "grid" of all possible combinations.
