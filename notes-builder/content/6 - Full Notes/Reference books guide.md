# Reference books guide
**Details**
Specifically in this section, we will be talking about two kinds, dictionaries and encyclopedias, although many of the things we talk about can apply to other reference books. 

Before using these books, you must at least have these kinds of knowledge in mind. If not, you may fail to use the book effectively, or use it at all. 

First is to have an idea of what you want to know. Second is know where to find what you want to know, and in turn you must know the major types of reference books to know which to use effectively. Third, is that knowing how to use those books (correlative to the former), this information can be found in the prefaces or just apply inspectional reading to it. Finally, you must know which questions of yours can be answered by this book and which cannot. This comes down to knowing the things that men generally agree on, because those things will be found in these reference books.
