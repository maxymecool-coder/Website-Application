# Raven's Progressive Matrices as a Culture-Reduced Test
**Details**
**Raven's Progressive Matrices** is a non-verbal test designed to be a "culture-reduced" or "culture-fair" measure of intelligence. It aims to minimize the impact of language and cultural knowledge, which can bias results in tests like the Stanford-Binet and Wechsler scales. This helped psychologists to achieve better results at understanding intelligence.

The test consists of a series of matrices (visual patterns) with one piece missing. The test-taker must choose the missing piece from a set of options, a task that requires abstract reasoning and rule inference—key components of **fluid intelligence**. Because it is non-verbal and requires simple instructions, it is considered fairer for individuals from diverse linguistic and cultural backgrounds. Its main limitation is that it provides only a single score for abstract reasoning, without identifying other cognitive strengths or weaknesses.
