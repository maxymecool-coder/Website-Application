# Comprehension Principle and Russell's Shadow
**Details**
Sets are typically named in two ways, listing elements or by providing a defining property for it. The latter relies on the Naive Comprehension Principle, which suggests that for any property, there exists a set containing exactly those things to satisfy said property, being $\{x : x \text{ is } \phi\}$.

However, the reason this is naive is because when pushed to the logical extreme, it actually fails. If we attempt to define a set consisting of "all sets that are not elements of themselves," we encounter **Russell's Paradox**. If this set contains itself, it contradicts its own definition; if it does not contain itself, it satisfies the definition and must be included. This paradox revealed that the naive ability to define sets by arbitrary properties is flawed, necessitating a more rigorous, restricted approach to set formation in twentieth-century mathematics to avoid such logical absurdities.
